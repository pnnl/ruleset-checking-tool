# Chiller - Rule 22-43    
**Schema Version:** 0.0.25   
**Mandatory Rule:** False    
**Rule ID:** 22-43      
**Rule Description:** When using performance curves from Normative Appendix J, chiller minimum part-load ratio (ratio of load to available capacity at a given simulation time step) and minimum compressor unloading ratio (part-load ratio below which the chiller capacity cannot be reduced by unloading and chiller is false loaded) shall be equal to 0.25.       
**Rule Assertion:** Baseline RMD = expected value   
**Appendix G Section:** Section G3.2.2.1 Equipment Efficiencies      
**90.1 Section Reference:** None  
**Data Lookup:** None  
**Manual Check:** No  
**Evaluation Context:** Chiller  
**Data Lookup:** None  
**Function Call:** 
None


## Applicability Check:  
- For each chiller in the baseline model: `for chiller in B_RMD.chillers:`
    - if the chiller has a condensing_loop and the chiller energy source is electricity then the rule is applicable, continue to rule assertion: `if chiller.consensing_loop != NULL and chiller.energy_source_type == "ELECTRICITY": CONTINUE TO RULE LOGIC`

**Rule Assertion:**
- Case 1: the chiller's minimum part-load ratio and minimum compressor unloading ratio are both equal to 0.25: PASS `if chiller.minimum_load_ratio == 0.25 AND chiller.minimum_unload_ratio == 0.25: PASS`
- Case 2: either the chiller's minimum part-load ratio or minimum compressor unloading ratio are not defined: UNDETERMINED `elif chiller.minimum_load_ratio == NULL OR chiller.minimum_unload_ratio == NULL: UNDETERMINED`
- Case 3: else: FAIL: `else: FAIL`

1. RCT should include the expected ratios and modeled ratios in the calc_vals for transparency.
